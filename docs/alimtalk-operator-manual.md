# 홈투게더 알림톡 운영 안내

기준일: 2026-09-19

**현재 자동 발송은 꺼져 있습니다.** NHN 템플릿 승인 확인 → 담당자 번호로 수신 테스트 → 운영 자동 발송 연결 순서로 준비합니다. 아래는 운영 시작 후 적용할 안내입니다.

## 1. 알림톡은 언제 보내나요?

고객의 **실제 계약 시작일과 종료일**을 기준으로 날짜를 계산합니다. 발송 시작 시간은 **오후 2시이며, 주말·공휴일도 동일**합니다.

| 구분 | 보내는 시기 | 안내 내용 |
| --- | --- | --- |
| 입주 1주차 | 계약 시작 7일 후 | 잘 적응하고 있는지, 불편한 점은 없는지 확인 |
| 첫 달 | 계약 시작 1개월 후 | 첫 달의 생활 상태와 필요한 도움 확인 |
| 월간 | 이후 매월 계약 시작일과 같은 일자 | 정기적인 생활 불편·도움 요청 확인 |
| 재계약 전 | 계약 종료 전 마지막 월간 안내일 | 계약 연장 또는 퇴실 의사 확인 |

**예시:** 2026년 2월 18일 ~ 2027년 2월 18일 계약이라면, 2월 25일 입주 1주차 → 3월 18일 첫 달 → 이후 매월 18일 월간 → 2027년 1월 18일 재계약 전 안내를 보냅니다.

날짜 계산에서 알아둘 점은 다음과 같습니다.

- 재계약 전 안내는 마지막 월간 안내를 대신합니다. 같은 날 두 번 보내지 않습니다.
- 계약 종료일 당일에는 보내지 않으며, 종료 30일 전 안내를 별도로 추가하지 않습니다.
- 31일처럼 해당 월에 없는 날짜는 말일로 맞춥니다. 예: 1월 31일 시작 → 2월 28일 → 3월 31일.
- 짧은 계약에서 월간 안내가 한 번뿐이면 재계약 전 안내로 바뀝니다. 월간 날짜가 없으면 종료 전 입주 1주차 안내만 보내며, 계약이 7일 이하면 보내지 않습니다.
- 재계약으로 확정된 새 계약은 입주 1주차·첫 달 안내를 생략하고, 새 계약 시작 1개월 후부터 월간 안내를 보냅니다. 마지막 월간은 재계약 전 안내로 바뀝니다.
- 처음 등록하기 전에 지난 일정은 보내지 않습니다. 당일 실행 지연은 오후 6시 정각까지 허용하며, 놓친 안내를 다음 날 자동으로 몰아서 보내지 않습니다.

회차에 맞는 알림톡 문구를 사용하며, 고객은 **‘체크인 응답하기’** 버튼으로 설문에 참여합니다. 문구를 바꾸려면 NHN 템플릿 등록·승인 상태도 함께 확인해야 합니다.

## 2. 고객정보는 어떻게 관리하나요?

고객정보의 원본은 Google 시트 **‘홈투게더_고객데이터’의 ‘게스트_마스터’ 탭**입니다. 고객정보 수정은 이 시트에서 진행합니다.

| 항목 | 운영 기준 |
| --- | --- |
| 반영 주기 | 매일 오전 6~7시 사이. 급한 변경은 수동으로 즉시 반영 |
| 저장에 필요한 정보 | 고객 ID, 이름, 유효한 연락처, 실제 계약 시작일·종료일 |
| 추가로 반영하는 정보 | 성별, 학교 또는 직장명, 고객상태 |
| 발송 대상 | 필요한 정보가 완성되고 고객상태가 **‘계약중’ 또는 ‘입주중’**인 고객 중, 오늘 발송 일정이 있는 고객 |
| 발송 보류 | 고객정보 누락, 다른 고객상태, 계약 종료, 계약 변경 확인 대기 등 |

고객정보가 저장됐다고 바로 알림톡이 발송되지는 않습니다. 해당 고객의 상태와 발송 일정도 맞아야 합니다.

**정보를 수정할 때**

1. 원본 시트에서 내용을 고칩니다. 고객 ID는 그대로 유지합니다.
2. 급한 변경이면 시트에 설치된 **‘고객 동기화’ 메뉴 → ‘저장 없이 확인’ → ‘지금 동기화’** 순서로 진행합니다.
3. 반영 결과에서 누락·확인 필요 고객이 있는지 확인합니다. 메뉴가 없거나 실행에 실패하면 시스템 담당자에게 요청합니다.
4. 당일 퇴실·전화번호 변경은 발송 전에 반영됐는지 꼭 확인합니다.

고객 ID는 같은 고객의 기록을 이어주는 번호입니다. 이름이나 전화번호가 바뀌어도 ID는 바꾸지 마세요. 기존 고객의 행을 삭제하거나 필수정보를 비우면 기록을 지우는 대신 발송이 보류됩니다.

**계약 날짜를 바꿨다면** 단순 정정인지 새 재계약인지 담당자가 확인해야 합니다. 시트만 수정하고 자동으로 발송 일정이 정상화됐다고 생각하지 마세요. 재계약 설문에 ‘연장 희망’으로 답한 것만으로 계약이 확정되지는 않습니다.

## 3. 고객의 응답 링크는 어떻게 사용하나요?

- 고객별·회차별로 서로 다른 전용 링크가 발급됩니다.
- 응답 기한은 **알림톡이 실제 전달된 시각부터 14일**입니다. 처음 열어본 날부터 계산하지 않습니다.
- 기한 안에는 같은 링크로 다시 들어갈 수 있지만, 같은 회차의 최종 응답은 한 번만 제출할 수 있습니다. 제출 후 수정 기능은 없습니다.
- 링크를 복사하거나 다른 사람에게 전달하면 그 사람도 같은 고객의 설문에 접근할 수 있습니다. 담당자도 고객 링크로 대신 제출하지 마세요.
- 번호를 수정해도 이미 보낸 링크가 자동으로 바뀌거나 회수되지는 않습니다. 잘못 보냈다면 시스템 담당자에게 해당 링크의 접근 차단을 요청합니다.
- 링크가 만료돼도 이미 저장된 응답 기록이 자동으로 삭제되지는 않습니다.

고객이 “이미 답변했어요” 안내를 보면 제출 완료 여부를 확인하고, “기간이 지났어요” 안내를 보면 응답 기한을 확인합니다. 수신 직후 일시적 오류가 보이면 잠시 후 다시 시도하도록 안내하고, 계속되면 시스템 담당자에게 확인을 요청합니다.

## 4. 관리자 페이지에서는 무엇을 하나요?

등록된 관리자 이메일로 로그인한 뒤 **‘응답’ 화면**을 사용합니다.

| 화면 | 확인할 내용 |
| --- | --- |
| 응답 목록 | 고객별 제출 내용. 긴급 → 불만 → 그 외 응답 순서 |
| 필터 | 회차, 불만 유무, 확인 여부, 접수 기간. 기본은 최근 30일 |
| 응답 상세 | 불만 내용, 고객정보, 계약 기간 |
| 과거 응답 이력 | 같은 고객이 이전에 남긴 응답 |
| 긴급 경로 진입 · 미제출 | 긴급 관련 항목까지 진행했지만 제출을 마치지 않은 기록. 확정 신고와 구분 |
| 확인 상태 | 내용을 확인한 뒤 ‘확인함으로 표시’, 필요하면 ‘확인 해제’ |

**권장 처리 순서:** 화면 새로고침 → 긴급·미제출 기록 우선 확인 → 미확인 응답 검토 → 필요한 연락·조치 → 확인 표시.

- 상세를 열기만 하면 확인 처리되지 않습니다. 직접 버튼을 눌러야 합니다.
- **‘확인함’은 내용을 읽었다는 뜻이며, 문제 해결 완료를 뜻하지 않습니다.** 연락 내용과 해결 여부는 팀의 상담 기록에 따로 남깁니다.
- 고객에게 연락할 때는 원본 시트의 최신 번호와 대조합니다. 상세에는 과거 계약 당시 정보가 보일 수 있습니다.
- 오래된 응답이 안 보이면 기간 필터를 넓혀봅니다. 조회 오류를 ‘응답 없음’으로 판단하지 않습니다.
- 현재 관리자 페이지에는 고객정보 편집, 발송 일정·실패 관리, 재발송 기능이 없습니다. 고객정보는 시트, 발송 결과는 NHN 콘솔과 시스템 담당자를 통해 확인합니다.

## 5. 담당자가 매일 확인할 것

| 시점 | 할 일 |
| --- | --- |
| 오전 | 고객정보가 정상 반영됐는지, 누락·보류 고객이 있는지 확인 |
| 발송 전 | 당일 연락처·계약·퇴실 변경 반영 여부와 발송 대상 확인 |
| 발송 후 | 실제 전달 성공·실패 확인. ‘발송 요청 접수’를 ‘전달 성공’으로 판단하지 않기 |
| 업무 중 | 관리자 화면에서 긴급·미확인 응답 확인, 연락·조치 기록 |

발송 실패나 결과 확인이 안 되는 건은 시스템 담당자에게 확인을 요청하세요. 이미 발송됐을 수 있으므로 임의로 다시 보내지 않습니다. 현재 미응답 리마인더와 실패 자동 재발송은 연결돼 있지 않습니다.

주말·공휴일에도 발송하므로 응답 확인 담당자를 정해두세요. 운영 시작 전에는 **담당자 번호로 수신 → 링크 열기 → 설문 제출 → 관리자 화면 확인**까지 한 번 끝까지 점검합니다.
